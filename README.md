# Knock Knock Chatbot

## Project Overview
This project is a Knock Knock Chatbot created using Google Cloud's Dialogflow and Vertex AI. It provides a fun and interactive way for users to engage with a chatbot that tells knock-knock jokes.

## Setup Instructions
### Prerequisites
1. Google Cloud account
2. Dialogflow API enabled
3. Vertex AI enabled

### Steps to Setup
1. **Create a new Dialogflow agent**:
   - Go to the Dialogflow console.
   - Click on "Create Agent".
   - Fill in the agent details and click "Create".

2. **Integrate Vertex AI**:
   - Navigate to the Vertex AI section on the Google Cloud console.
   - Create a new model suitable for your chatbot capabilities.

3. **Connect Dialogflow with Vertex AI**:
   - In the Dialogflow console, go to your agent settings.
   - Under the "Integrations" tab, enable the integration with Vertex AI.

4. **Set up intents for Knock Knock jokes**:
   - In Dialogflow, go to the Intents section.
   - Create intents for each knock-knock joke you want the bot to tell.

5. **Test the chatbot**:
   - Use the built-in simulator in Dialogflow to test your chatbot's responses.
   - Ensure the integration with Vertex AI is functioning as expected.

Enjoy your Knock Knock Chatbot! 🎉
